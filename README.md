Switching Between Solutions:

Both solutions use the Person class, but they require different implementations of ToString() in Person.cs.

Solution 1 – Sort Persons by Name and Age

In Person.cs, uncomment the Solution 1 implementation of ToString() and comment out the Solution 2 implementation.
In Program.cs, uncomment Solution 1 and comment out Solution 2.

Solution 2 – Salary Increase and Validation

In Person.cs, comment out the Solution 1 implementation of ToString() and uncomment the Solution 2 implementation.

In Program.cs, comment out Solution 1 and uncomment Solution 2.

Important: Make sure only one ToString() implementation is active in Person.cs and only one solution is active in Program.cs at a time.

Solution 1 at the start is the solution that in the beginning is commented out
